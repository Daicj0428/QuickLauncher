快捷启动台 QuickLauncher 使用说明
==================================

一个托盘常驻小工具，功能：
  1. 双击托盘图标 → 打开整体编辑窗口；右键托盘图标 → 快速切换模式
  2. 🚀 快速切换模式：每种模式保存一组应用 + 音量 + 分辨率/刷新率设置，
     右键托盘一键切换（会先停掉其他模式由本程序拉起的进程）；
     启动前会先检查，已经在运行的应用直接跳过、不重复开
  3. ⚙ 整体编辑窗口：六个页面图形化编辑，保存即生效；
     最小化或点 ✕ 时隐藏到托盘，不退出
  4. 首次启动自动获取开始菜单里的全部应用（自动排除系统内置的），
     填入应用列表；之后你自己删改不会再被覆盖
  5. 快速调节：网络（代理开关 / DNS / WiFi / 网卡）、音量、分辨率与刷新率
  6. 启动时自动检测本机应用与系统配置，生成报告并弹窗摘要

一、启动
--------
  方式 A（推荐）：双击 QuickLauncher.exe —— 单文件可执行版，静默进入
            右下角系统托盘，无控制台窗口。
  方式 B：双击 start.bat —— 同目录有 QuickLauncher.exe 就用它，
            没有则用 Python 运行 launcher.py。
  方式 C：命令行  python launcher.py

  首次启动会自动检测系统配置并把检测到的应用写入配置，稍等几秒会弹窗摘要。
  检测报告保存在 data/reports/ 下。

二、托盘交互
------------
  双击图标 = 打开整体编辑窗口。
  右键图标 = 快速切换模式菜单：
    · 🚀 模式名 —— 一键切换到该模式（自动应用其保存的音量/显示设置并启动应用）；
                    切换过的那个模式后面会标上 “✅ 当前”，一看就知道现在是哪个模式
                    （点【🛑 全部停止】后标识清除，重启程序也会记住）
    · 🛑 全部停止 —— 停止所有由本程序拉起的进程
    · ⚙ 整体编辑 —— 打开设置窗口（同双击）
    · ❌ 退出程序 —— 完全退出（会先关闭编辑窗口、移除托盘图标）
  启动前会先检查这个应用是否已经在运行（按 exe 名比对进程列表），
  已经在运行的就跳过不再启动一次，提示里会显示“已在运行, 跳过 N 个”。
  切换模式时，会先把不属于这个模式的应用（由本程序拉起过的）自动停掉，
  再启动本模式的应用；提示里会显示“已停掉不属于本模式的 N 个应用 / M 个进程”。
  · 新模式也要用的应用（比如两个模式都有 Chrome）会保持运行、不会被停掉再重开；
  · 想让它永远不被切换停止，就加到“全局保留应用”列表里（见第三节），
    提示里会显示“保留运行 N 个(本模式要用 / 全局保留)”。
  模式名带 ⚙ 后缀表示该模式保存了音量/显示设置（选中后右侧“当前设置”显示细节）。

  Windows 11 里图标可能在任务栏右侧的 ^ 隐藏区，按住它拖到任务栏即可固定。

三、⚙ 整体编辑窗口（推荐）
--------------------------
  双击托盘图标打开 —— 窗口是提前在后台建好的，所以几乎秒开；
  深色科技感界面（连标题栏也是深色，没有顶部白边），共六个页面：
    · 🚀 应用列表 —— 增删改应用；每个应用带真实图标显示（图标+名称+路径）；
      下拉框可直接选择检测到的已装应用；
      【🔄 一键填充全部应用】把检测结果整体填入
    · 🚀 自定义模式 —— 管理模式和应用（应用同样带图标显示）；
      模式名后面带 ⚙ 表示它保存了 音量/显示 设置，选中后右侧“当前设置”
      会显示具体数值；右侧可给当前模式保存 音量% + 显示模式
      （启动该模式时自动应用）；
      🌍 全局保留应用 —— 在这里填 exe 文件名（多个用逗号分隔，
      例：chrome.exe, WeChat.exe），切换模式时这些应用永远不会被停掉；
      也可以先在下方应用库选中一条，再点【＋ 用应用库选中】自动填入；
      底部“📋 应用库”自带【🔎 搜索】框，输入名称或路径片段即时过滤，
      单击某一行的图标即可把它加进左侧选中的模式
    · 🌐 网络设置 —— 分三个子页：
        📶 WiFi (无线)   —— 列出所有已保存的 WiFi，双击即连接；
                            右侧可直接改密码(👁 可显示)、开关自动连接，
                            【💾 保存修改】写回系统；可断开/删除配置。
        🔌 以太网 / 网卡 —— 列出全部网卡(有线/无线/虚拟)，显示
                            状态、DHCP/静态、IPv4 地址；选中后可直接
                            编辑 IP / 子网掩码 / 网关 / 主备 DNS，
                            【💾 应用静态配置】【↩ 改回 DHCP】；
                            还能启用/禁用单个网卡、打开网络连接面板。
        🌐 代理 / DNS   —— 系统代理地址、DNS 方案预设、网络状态 /
                            代理开关 / DNS 一键应用 / 网卡全启用等快捷操作
    · 🔊 音量 —— 滑杆调音量、静音开关、20~100% 预设
    · 🖥 显示设置 —— 切换分辨率/刷新率、恢复推荐模式
    · ⚙ 系统 —— 开机自启开关、重新检测配置、打开报告/文件夹、
      以管理员重启、退出程序
  点【💾 保存并生效】立即写入配置，不用重启程序。
  最小化或点右上角 ✕，窗口隐藏到托盘，程序继续后台运行；
  双击托盘图标随时重新打开。

四、自定义模式（一键切换）
--------------------------
  在“整体编辑窗口 → 🚀 自定义模式”页维护，也可在 config.json 的
  "modes" 里手工定义：
      "modes": [
        {"name": "工作模式",
         "settings": {"volume": 60, "display": {"w": 2560, "h": 1600, "hz": 240}},
         "apps": [
            {"name": "VS Code", "path": "C:\\...\\Code.exe", "stop": "Code.exe"},
            {"name": "Chrome",   "path": "C:\\...\\chrome.exe"}
        ]}
      ]
  "stop" 字段可选：停止时按进程名杀（如 "chrome.exe"）；不写则自动取
  路径里 exe/bat/cmd 的文件名作为进程名。
  "settings" 可选：volume 0-100；display 为主显示器分辨率/刷新率，
  或 {"recommended": true} 表示恢复推荐模式。启动/切换该模式时自动应用。

  右键托盘 → 点模式名 = 快速切换：
    停掉其他模式由本程序拉起的进程（新模式也要用的应用会保留运行）
    → 应用该模式的音量/显示设置 → 启动该模式应用（已在运行的直接跳过）。
  停止只针对“本程序拉起的”进程，不影响你自己打开的窗口。

五、权限说明
------------
  音量、代理、分辨率/刷新率、启动应用、查看 WiFi 密码/网卡信息：
      无需管理员权限。
  WiFi 改密码/删除配置、改 IP / 子网掩码 / 网关 / DNS、网卡启用禁用：
      需要管理员权限，点按钮后会弹 UAC 确认框，点“是”即可。
      也可以在整体编辑窗口【⚙ 系统】页点【以管理员身份重启】，
      重启后所有网络操作都不再弹 UAC。

六、开机自启
------------
  整体编辑窗口【⚙ 系统】页 →【开机自启 开 / 关】。
  开启 = 在用户启动文件夹创建快捷方式，再点一次取消。

七、其他
--------
  - 分辨率/刷新率列表来自显卡驱动支持的模式；切换后想恢复，
    点【↩ 恢复推荐模式】。
  - 网络设置改完立即生效；改 IP 后建议先确认新地址可上网，
    若改错可在同一页点【↩ 改回 DHCP 自动获取】恢复。
  - 禁用当前活动网卡会立即断网，按钮上已标注。
  - 运行日志：data/log.txt；配置文件：config.json；检测到的应用：data/apps_detected.json
  - 退出：整体编辑窗口【⚙ 系统】页 →【退出程序】。
  - 可执行文件版：QuickLauncher.exe 与 config.json、data\ 放在同一目录；
    换目录时把这几样一起搬走即可。
  - 依赖安装（仅源码方式运行需要）：pip install pystray pycaw comtypes pillow

八、故障排查
------------
  - 双击 start.bat 没反应：直接双击 QuickLauncher.exe；仍不行则
    运行  python launcher.py  看报错信息。
  - 托盘图标不显示：Windows 11 可能在 ^ 隐藏区里，拖到任务栏即可。
  - 切换分辨率失败：该模式不被当前驱动支持，换一个模式试试。

九、性能说明
------------
  · 双击托盘：窗口在程序启动时已在后台建好，双击只做“显示”，通常在 0.3 秒内出现；
    配置没改动时不会重新读取任何系统信息。
  · 网络页：WiFi 列表、当前连接、网卡列表在后台并行读取（约 0.7 秒填满），
    界面不会卡住；点某一行时详情也是后台读取，先显示“读取中…”。
  · 应用图标：第一次提取后会缓存到 data/icons/，之后再打开不再重复提取。
  · 所有 netsh / tasklist / taskkill 等命令都在隐藏窗口里执行，
    不会再弹黑色 cmd 窗口（只有需要管理员权限的操作会弹 UAC 确认框）。

十、装到别的电脑上
------------------
  这个程序是免安装的绿色软件，Windows 10 / 11 (64 位) 直接能用，不需要装 Python。

  方式 A：绿色版（最简单）
    把整个文件夹拷到新电脑（U 盘、网盘都行），双击 QuickLauncher.exe 即可。
    首次启动会在同目录自动生成 config.json 和 data\，并自动扫描本机应用。
    想换位置就把整个文件夹搬走，配置跟着走。

  方式 B：安装版（推荐给不常用文件夹的人）
    1) 双击 install.bat；
    2) 会问装到哪个目录：
         · 直接回车 = 默认 %LOCALAPPDATA%\Programs\QuickLauncher（当前用户目录，不需要管理员）
         · 也可以自己输入，例如 D:\Apps\QuickLauncher
       目录没有写入权限时会提示换一个（最多试 3 次）；
    3) 自动创建桌面快捷方式“快捷启动台”；
    4) 会问要不要开机自启，输入 Y 开启，直接回车跳过；
    5) 安装完自动启动。
    卸载：双击 uninstall.bat —— 它会记住上次装到哪（记录在注册表
          HKCU\Software\QuickLauncher 的 InstallDir 里），自动关闭程序、
          删除快捷方式和安装目录；也可以给 uninstall.ps1 传 -Target "路径" 指定。

  注意：
  - 应用路径是本机的，换电脑后首次会自动重新扫描；
    若想手动重扫：设置窗口 → 🚀 应用列表 →【🔄 一键填充全部应用】。
  - 模式里保存的应用如果新电脑上没有，启动时会提示“启动失败”，
    在模式页把它们删掉或换成新电脑上的应用即可。
  - 网络/音量/分辨率 这些功能依赖 Windows 自带的 netsh / 系统音量接口，任何 Windows 电脑都能用。

  · 版本：v1.7
